# Kalkulator Sederhana Python

Program kalkulator berbasis Command Line Interface (CLI) menggunakan Python untuk operasi aritmatika dasar.

## Fitur
- Penjumlahan, pengurangan, perkalian, dan pembagian
- Penanganan *error* untuk pembagian dengan nol
- Validasi *input* non-angka

## Cara Menjalankan
1. Pastikan Python 3 sudah terpasang di sistem Anda.
